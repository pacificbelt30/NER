    SERVER PREFERENCES

    設定

    翻訳方式の準備手順と設定状況の確認、PDFの保存期間の設定ができます。

    翻訳方式の準備

    使いたい方式を開くと、必要なもの・準備手順・設定例を確認できます。

    翻訳エンジンの設定は、NERを動かしているサーバーの config.yml（NER_CONFIG_PATH 指定時はそのファイル）を編集します。この画面は手順の案内と設定状況の確認です。

    設定例は既存の同名セクションを置き換えて使ってください。既定の方式も変える場合は PRIORITY を変更します。通常は保存後の再確認で反映します。Dockerで設定ファイルの差し替え・マウント変更をした場合はコンテナも再起動してください。

    「設定済み」は設定の形式を確認した状態です。接続先の稼働・認証・モデル推論は、実際に翻訳するまで未確認です。

    翻訳画面へ戻る →

    翻訳履歴の保存期間

    原文・訳文・比較用PDFと履歴をサーバに保存します。既定は無期限です。

    日間

    サーバ全体の設定です。変更は今後完了する翻訳に適用します。
    保存済みPDFの期限は変わりません。期限を過ぎたPDFと履歴は自動で削除されます。
